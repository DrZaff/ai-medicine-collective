CSV Cleaner

Upload a CSV or Excel export, look it over, then clean it with one click. Every change is listed for you, and missing values are flagged — never filled in.

No file handy? (made-up patients). Cleaning runs here in your browser; your file isn't uploaded to a server. Still, follow your institution's rules before using it with patient data.

Change summary

    Column by column

    Change a column's formatting here, or open Rules to set allowed values and ranges and to merge different spellings of the same thing. Starting rules are suggested from the column names; edit them to fit your data.

    Rows with the same values in these columns but differences elsewhere are flagged as possible duplicates. They are not deleted.

    Save these rules for next time

    Save your formatting, rules, merges and record ID columns so next month's export is cleaned the same way. Saving in this browser is easiest; a rules file can be shared or kept as a backup.

    Check the result

    Compare with a sample you cleaned by hand

    Pick 30–50 of the messiest rows, clean them yourself, and save them as CSV or Excel with the same column names. The tool should match you exactly.
